## 🌐 How to View & Run the Website

### Option 1: Direct File Open (Zero Config)
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Brave, Safari). It is fully self-contained!

### Option 2: Local Web Server (Node.js)
In this directory, you can run:
```bash
npx serve -l 3000 .
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.
